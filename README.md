# Comix extension (joclio)

Tracks **[Keiyoushi Comix](https://github.com/keiyoushi/extensions-source)** (published extension **1.6.54**).

**joclio build:** **v1.6.114** (`versionCode` 106114). Exact re-issue of the last working jar (**1.6.110**) — no other code changes. Use this to restore reader/WebView after later experiments.

## Install on Tachimanga (iPad/iPhone)

### Extension repository (recommended)

```
https://raw.githubusercontent.com/joclio/extensions/main/index.pb
```

Needs Tachimanga **4.16 or newer** (extension library 1.6). Remove the repo entry → force-close Tachimanga → reopen → add the URL again → **Browse → Extensions → refresh**. Uninstall every Comix row first (including 1.6.111–1.6.113 and Keiyoushi **1.6.54**), force-close Tachimanga, refresh the repo, then install **Comix English 1.6.114** only. If Web View still shows “Third-party apps are not supported”, open **Web View** from the source, wait until the normal Comix site loads (pass Cloudflare if asked), then try again.
