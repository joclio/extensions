# Comix extension (joclio)

Tracks **[Keiyoushi Comix](https://github.com/keiyoushi/extensions-source)** (published extension **1.6.54**).

**joclio build:** **v1.6.138** (versionCode 106138). Slim chapter walker; keeps walking past HiveToons-only pages until the lagging group (e.g. Webtoon) is found. Does not replace the library with a filtered list.

## Install on Tachimanga (iPad/iPhone)

### Extension repository (recommended)


https://raw.githubusercontent.com/joclio/extensions/main/index.pb


Needs Tachimanga **4.16 or newer**. Refresh the repo, install **Comix English 1.6.138**, confirm Web View, then update **Reborn Rich** (allow a longer refresh).

### Manual install

https://github.com/joclio/extensions/releases/latest
