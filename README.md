# Comix extension (joclio)

Tracks **[Keiyoushi Comix](https://github.com/keiyoushi/extensions-source)** (published extension **1.6.54**).

**joclio build:** **v1.6.137** (versionCode 106137). Stock WebView chapter walker with **slim JSON** (no queries blob) so the jsBridge does not truncate. Section wait 18s. Avoid 1.6.134–135 (library wipe).

## Install on Tachimanga (iPad/iPhone)

### Extension repository (recommended)


https://raw.githubusercontent.com/joclio/extensions/main/index.pb


Needs Tachimanga **4.16 or newer** (extension library 1.6). Remove the repo entry → force-close Tachimanga → reopen → add the URL again → **Browse → Extensions → refresh**. Install **Comix English 1.6.137**.

Confirm **Web View**, then update affected series once to reload chapters.
