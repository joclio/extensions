# Comix extension (joclio)

Tracks **[Keiyoushi Comix](https://github.com/keiyoushi/extensions-source)** (published extension **1.6.54**).

**joclio build:** **v1.6.121** (`versionCode` 106121). Same WebView/reader baseline. Hardens chapter capture for Tachimanga’s JS engine (no modern null operators, JSON XHR bodies, broader DOM scrape).

## Install on Tachimanga (iPad/iPhone)

### Extension repository (recommended)

```
https://raw.githubusercontent.com/joclio/extensions/main/index.pb
```

Needs Tachimanga **4.16 or newer** (extension library 1.6). Remove the repo entry → force-close Tachimanga → reopen → add the URL again → **Browse → Extensions → refresh**. Install **Comix English 1.6.121**. Confirm Web View still works, then update a series that has a newer chapter on the site than in your library.

### Manual install

https://github.com/joclio/extensions/releases/latest
